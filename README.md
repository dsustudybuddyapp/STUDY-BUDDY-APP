## Overview

### Description

An app that helps students stay organized by keeping track of assignments, upcoming deadlines, and study sessions. Users can add their own assignments and set when they're due

### App Evaluation

[Evaluation of your app across the following attributes]
- **Category: Productivity**

- **Mobile:** Users can manage assignments on their phones and receive notifications about upcoming deadlines. I could also add a study timer.
- **Story:** Helps students stay organized and avoid forgetting assignments or deadlines.
- **Market:** High school and college students who need help managing their schoolwork.
- **Habit:** Students could use the app daily to check assignments, add new tasks, and track their progress.
- **Scope:** Manageable to build using Android Studio. I can start with adding assignments, setting deadlines, and marking tasks as completed. More features can be added later.

## Product Spec

### 1. User Features (Required and Optional)

**Required Features**

1.Users can add new assignments by entering an assignment name, description, and due date.
2. Users can view a list of their assignments and see when each assignment is due.
3. Users can mark assignments as completed.

**Optional Features**

1. Users can view their progress by seeing how many assignments they've completed.
2. Users can delete assignments they no longer need.
3. Users can put how long they worked on an assignment.

### 2. Screen Archetypes

- Home Screen
  - Users can see welcome text and their upcoming assignments and due dates.
- Assignments screen
  - Users can see a full list of all their assignments and due dates.
  - Users can mark things off as completed.
- Add assignment Screen
  - Users can add an Assignment by includingits name,description and due date.

### 3. Navigation

**Tab Navigation** (Tab to Screen)

* Home Tab → Home Screen
* Assignments Tab → Assignments Screen

**Flow Navigation** (Screen to Screen)

- **Home Screen**
  - Users can navigate to the Assignments Screen using the Assignments tab.

- **Assignments Screen**
  - Users can navigate to the Home Screen using the Home tab.
  - Users can tap the Add Assignment button to open the Add Assignment Screen.
  - Users can mark assignments as completed.

- **Add Assignment Screen**
  - Users can save their assignment and return to the Assignments Screen.
  - Users can go back to the Assignments Screen without saving.
